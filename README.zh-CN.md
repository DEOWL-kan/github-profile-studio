# github-profile-studio

一个 Claude skill，帮你做一个真正代表自己的 GitHub 个人主页：展示你想展示的内容，用你喜欢的风格，信息都真实可查。发布之前，深色和浅色两种主题都会先预览给你看。

## 能做什么

- **仿照别人的主页，只学风格不抄人。** 给出你喜欢的主页，它会拆解出对方的许可证、版式、用了哪些组件、每个组件是怎么生成的，然后用你自己的数据做出类似的效果。
- **画像名片。** 把照片、你选的角色或者 GitHub 头像，做成 neofetch 风格终端卡片里的彩色 ASCII 画像。卡片上的 GitHub 统计每天自动刷新。附带工具可以从复杂的画面里抠出人物，并修补缺口。
- **组件与分区。** 常见组件一览：统计卡、打字动画、技能图标、贡献图贪吃蛇、博客订阅、项目表格等，并注明哪些是第三方实时服务、哪些是在你自己仓库里生成的。
- **展现真实实力。** 先给主页做一次体检：简介、置顶、仓库门面这些弱项按优先级列出来，同时挑出你最有说服力的证据，比如合并进热门项目的 PR。它只放大你真实的实力，不帮你造假，像伪造贡献图、买星这类做法会直接拒绝。
- **内容有取舍。** 先问清楚什么要展示、什么要保密，把项目和贡献讲清楚；语言列表按你真实提交过的代码统计。
- **真实预览，稳妥发布。** 用 GitHub 自己的 Markdown 渲染，按主页宽度出深色、浅色两版预览。只有你同意后才会发布，发布后还会检查线上页面。

## 安装

把这个目录复制或克隆到你的 skills 目录，例如：

```bash
git clone https://github.com/DEOWL-kan/github-profile-studio ~/.claude/skills/github-profile-studio
```

然后直接对 Claude 说，比如：
- "把我的 GitHub 主页做好看点"
- "用这张图做我的主页名片"
- "我喜欢某某的主页，照着做一个我的"
- "主页展示我的开源贡献，但不要出现公司项目"
- "让我的主页看起来更像一个厉害的开发者"

## 依赖

`gh`（需已登录）、Python 3（只用标准库）、ImageMagick 7（`magick`）、用于预览的 Chrome 或 Chromium；`rsvg-convert` 可选。
