# Path C — building blocks

Read this when composing a README from sections and widgets, or when a replicated profile uses them. For each block: what it is, how it is produced, and what to watch for. Project details change, so check each project's README for current parameters before using it.

## How a block is produced matters most

- **Live third-party service** (an image URL with your username in it): zero setup, but it can be slow, rate-limited or down, and your page shows a broken image when it is. Public instances of popular services are often overloaded.
- **Generated by a workflow into the repo** (an Action writes an SVG, commits it, and the README points at the file): needs a workflow, but it is fast and reliable, and you control it. Prefer this for anything central to the page.
- **Static**: an image or GIF you commit or upload once.

## What GitHub renders, and what it strips

- Markdown plus a subset of HTML: `<p align>`, `<img width height>`, `<picture>`/`<source>`, `<table>`, `<details>`/`<summary>`, `<a>`, `<br>`, `<sub>`/`<sup>`, `<kbd>`.
- `style` attributes, `<style>` tags, scripts and iframes are removed. Layout comes from tables, `align`, image widths and whitespace.
- Images go through GitHub's image proxy (camo). An SVG is shown as an image: CSS animations inside it run, but scripts do not, and external fonts or images referenced inside the SVG do not load. Use system font stacks or outline the text.
- Theme switching: `<picture>` with `prefers-color-scheme` sources is the robust way. `#gh-dark-mode-only` and `#gh-light-mode-only` URL fragments also work.
- Width: the desktop README column is about 830 px; on phones it is much narrower, and images scale down. Test that text inside images stays legible.

## Composition that tends to look good

- One hero element, then at most two or three supporting blocks. Stacking every widget turns the page into noise.
- Consistent colours across blocks. Most widgets take theme or colour parameters, so align them with the hero.
- Check both themes; a widget that looks fine in dark can vanish in light.
